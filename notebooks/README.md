# Notebooks

Run notebooks with the repository root as the current working directory.

- `MTSD_Object_Detection.ipynb` is the original YOLO and dataset workflow. In this submission copy, workstation-specific source paths were converted to repository-relative paths; the original training logic was otherwise preserved. Place the original annotations and images in the folders described in `data/README.md`.
- `02_CNN_Training_and_Experiments.ipynb` contains the recovered CNN training sequence from the original IPython session. It includes dataset processing, model setup, baseline and augmented training, and plots.

The notebooks do not store outputs in this submission copy. Raw metrics, training histories, plots, and YOLO run configuration are included under `results/`.
