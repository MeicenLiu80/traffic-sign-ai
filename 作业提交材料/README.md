# 作业提交材料

这里集中保存本项目的课程提交材料；报告和视频尚未制作完成。

## 技术报告

- 要求：4–6 页、双栏学术论文格式。
- 至少包含 Introduction、Related Work、Methods、Results、Conclusion 和 References。
- 把最终 Word/PDF 文件放入 `技术报告/`。

## 展示视频

- 时长：3 分钟。
- 清楚介绍问题、方法、结果和主要结论，面向技术观众。
- 可使用讲解、幻灯片、屏幕录制或网站演示。
- 把最终视频放入 `展示视频/`。
