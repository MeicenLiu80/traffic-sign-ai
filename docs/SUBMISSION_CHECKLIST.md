# GitHub submission checklist

| Instructor requirement | Included in this draft | Status |
|---|---|---|
| Complete source code | Flask website, frontend, YOLO and CNN training notebooks, and inference scripts | Included |
| Trained models or reproduction instructions | YOLO and both CNN checkpoints are included; notebooks document training and validation | Included |
| Experimental results | CNN histories/comparison, data quality reports, YOLO metrics/configuration, and inference CSV | Included |
| Comprehensive README | English and Chinese guides explain objective, setup, use, pipeline, findings, and limitations | Included |
| License and attribution | Project released under AGPL-3.0; MTSD source and terms linked; full dataset not redistributed | Included |

The project owner has approved publishing the project code, trained checkpoints, and current demo visuals. The root `LICENSE` uses AGPL-3.0 to align with the Ultralytics YOLO package/model used by this project. The repository links to MTSD and does not contain the complete dataset.

Before upload, create the initial Git commit and connect this folder to the intended GitHub repository. The technical report and 3-minute presentation video are separate deliverables.
